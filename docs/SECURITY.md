# Privacy and security boundary

**Sensitive data:** The user's inbox contents, sender details, Apple app-specific password, and account identity. The Git repository is currently PUBLIC. Use synthetic `example.test` fixtures only; no real mail in PR comments/CI output.

1. **Consent:** Only connect with the mailbox owner's explicit consent. `ICLOUD_MAIL_ACCOUNT_CONSENT=yes` is an operator-controlled guard, not proof that the account owner granted consent. Obtain and maintain that consent separately; revoke on request.
2. **Credentials:** User creates a separate Apple app-specific password at `account.apple.com`. Inject as an ephemeral secret on a trusted host; do not use the Apple Account primary password, commit to Git, paste into ChatGPT, store in a plaintext env file, or print exceptions containing credential values. Revoke through Apple Account Settings immediately if compromised or when no longer needed.
3. **IMAP:** TLS with OS certificate validation, pinned Apple server `imap.mail.me.com:993`, readonly `INBOX` select and `BODY.PEEK[]` UID fetch only. No write methods, SMTP, persistent caches, or background polling. Small input quotas: last 200 search UIDs, <=30 results, <=256 KiB/message, <=700 characters of visible text per message. Oversized messages are skipped.
4. **Prompt injection:** The content of an email is inherently untrusted. It may say “ignore previous instructions,” contain fake tool calls, or solicit credentials. The tool returns structured untrusted fields. The summarizing assistant may describe such claims but must never execute them, follow links, forward mail, or promote source text into authority.
5. **Network:** This prototype allows only process-private stdio. **Do not run a public MCP endpoint or expose this server via a tunnel without tested OAuth 2.1, HTTPS, per-user access controls, request logging without personal contents, rate limits, and owner consent.** Single environment variables are not a substitute for user authentication on public HTTP endpoints.
6. **Third parties:** If installed into ChatGPT, the returned email excerpts will be transmitted to OpenAI as part of the conversation. The mailbox owner must be informed and consent. Model/provider retention rules apply independently of this repository.
7. **Incident response:** Disconnect plugin, stop backend, revoke the app-specific password in Apple Account, investigate access logs without copying email contents, rotate authorization keys, and verify no user data was committed. Git history still exists after deleting a file, so never commit sensitive data at any point.

**Known gaps / not production-hardened:** No live OAuth flow, no verified ChatGPT Free app installation, no outbound HTTPS deployment, no independent production vulnerability review, no auth against an actual iCloud mailbox, no automated secret vault integration, no signed-release supply-chain lock, no installed-host runtime receipt. See `docs/DELIVERY.md`.
